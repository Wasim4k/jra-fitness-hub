IMAGE FOLDER STRUCTURE
=======================
/assets/images/hero/            -> hero background + athlete cutouts
/assets/images/about/           -> about section photos
/assets/images/trainers/        -> trainer headshots (recommended 600x700px)
/assets/images/gallery/         -> gym interior photos (recommended 800x600px)
/assets/images/transformations/ -> before/after client photos
/assets/images/icons/           -> custom icon assets (optional, Font Awesome used by default)
favicon.png                     -> site favicon, 512x512px recommended

NOTE: This build ships with elegant CSS/SVG-driven visuals (glass cards, icon
frames, gradient orbs) in place of real photography, since no licensed brand
photos were provided. Drop real photography into the folders above using the
same file names referenced in the HTML (or update the <img>/background paths)
to instantly upgrade every section to full photographic quality.
